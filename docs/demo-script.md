# 60-second demonstration

Use headphones or capture system audio. Start on the original **After hours** composition with the drum grid visible. The app never autoplays. This script works with the delivered manual studio; an alternate live-AI segment is clearly marked below.

| Time   | Action and narration                                                                                                                                                                         |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–8s   | Show the console. “This is VibeConductor: three original instruments, one small studio, and a score you can inspect.” Press Play.                                                            |
| 8–17s  | Point out the reacting drum pads, speaker and keys. “These react to the notes you hear. The audio clock keeps time independently of the interface.” Toggle an empty drum step.               |
| 17–25s | Show the queued-change indicator, then let the next loop begin. “Edits enter together at the next available loop, so a change never tears the current phrase apart.”                         |
| 25–36s | Select Lead, add a note and adjust its duration. “The piano roll gives me direct control. The instrument works completely without an AI account.”                                            |
| 36–45s | Undo; open Versions and compare a prior version, then return to current. “Versions are real scores. A late AI response cannot overwrite a newer manual edit or resurrect something I undid.” |
| 45–54s | Save, create a share link, open that snapshot and press Play. “Sharing freezes this musical moment. Further edits stay private.”                                                             |
| 54–60s | Show JSON and WAV export. “The same musical event compiler powers playback, saving and offline audio. No regenerated interpretation is needed.”                                              |

If a real key has been configured and a live request succeeds, replace seconds 25–36 with: lock Bass, type **Give the lead more space**, show the returned explanation and highlighted notes, then let the next loop play. Say “The model proposes musical changes; independent validation protects the score.” Do not present a mocked response or manually edited example as live AI. If the request takes longer, extend the recording rather than disguising latency.

Local share URLs work only while this server is reachable. For a public demo, deploy the documented password-protected server and use its configured HTTPS origin.
